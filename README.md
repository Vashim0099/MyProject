HOW TO SETUP C COMPILER : 
       
        1] Download GCC or MINGW From Sourceforge net and install it . 
        
        2] Open and run .
       
        3] Select GCC and necessary tool and click on apply change and ok.
       
        4] open C Drive and open MINGW and then GCC and bin 
       
        5] Now copy (CTRL+C) by right click on the address or location
       
        6] click on window icon and search environment variable .
       
        7] Select path and then paste the address using (CTRL+V).
       
        8]Then click on OK and OK and OK.
       
        9] Go to terminal and open with  run as administrator.
      
        10] Type command ( gcc --version ) if show version details it successfully setup .
       
        11] Now you can C langauge in VS , zed etc IDE.
